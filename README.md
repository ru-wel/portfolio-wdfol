## Images

Content data (`src/assets/projects.js`, `certificates.js`) points at the original files in `public/images`. The site serves WebP copies built from them: a full-size one for the image viewer and an 800px one for cards and previews. After adding or replacing an image, run:

```sh
npm run images
```

This needs macOS (`sips`) and `cwebp` (`brew install webp`). It rewrites `public/images/webp/` and `src/assets/imageSizes.js`.
